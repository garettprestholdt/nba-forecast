How it works

The model

How the forecasts are made, how they were tested before going live, and how they're scored every morning since.

{% endblock %} {% block content %}

1 · Ratings

Every team gets a number

An Elo rating, updated after every game: beat a good team by a lot and it goes up a lot. A team's rating in points is how much better than an average team it is, per game. Home court is learned from recent games (worth {{ "%.1f" | format(home_court_points) }} points today), and ratings drift {{ "%.0f" | format((1 - model_params.carryover) * 100) }}% back toward average each summer.

2 · Players

A challenger that knows who's playing

A second model adds the players: each one's production (Game Score per minute) and offense and defense impact (how the score moves with them on the floor, adjusted for the other nine), weighted by who's available tonight on the morning injury report, plus the value of whoever is out. In testing it beat the published model; it now runs in shadow mode and takes over only if it wins this season by a rule set in advance.

3 · Scored in public

No editing the past

Every morning a scheduled job adds last night's results, updates the ratings, and logs today's forecasts to an append-only record. A check blocks the save unless every forecast is new and made before tip-off. Each one is scored once its game is final, next to the betting market's.

Glossary

Reading the numbers

Log-loss: the main score. It rewards confident correct forecasts and punishes confident misses; lower is better, a coin flip scores 0.693. Calibration: do 70% forecasts win 70% of the time? Game Score: John Hollinger's one-number box score, about 10 for an average game.

Is it any good?

Before going live, every approach below predicted six full seasons ({{ "{:,}".format(simple_backtest[0].games) }} games, 2020-21 to 2025-26) using only what it could have known at the time. "Picks right" is how often the favorite won. Log-loss also rewards being confident when right and humble when unsure; lower is better.
