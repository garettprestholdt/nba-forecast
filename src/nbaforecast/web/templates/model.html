Model & backtest

How the forecasts are made, how they were tested before going live, and what the test found.

How it works

  • Elo ratings, following FiveThirtyEight's NBA design: K = {{ model_params.k | int }}, a margin-of-victory multiplier that discounts blowouts by heavy favorites, and {{ "%.0f" | format(model_params.carryover * 100) }}% of each rating carried into the next season.
  • Adaptive home court: the home bonus is learned from the last {{ "{:,}".format(model_params.hca_window) }} non-neutral games instead of fixed. It's {{ "%.0f" | format(home_court) }} Elo points today. Neutral-site games get none.
  • No look-ahead: every game on a date is predicted from the ratings at the start of that day, the same way the daily job publishes each morning.
  • Every morning GitHub Actions adds last night's results from ESPN, updates the ratings, predicts the day's games, and attaches the betting market's consensus (median de-vigged moneyline across sportsbooks). A check rejects the commit unless every prediction is new and was made before tip-off.

What the test found: home-court advantage shrank, from 60.5% home wins in 2004-05 to 54.4% in 2024-25. The fixed home bonus chosen on the early seasons kept forecasting about 60%, so it was miscalibrated on recent seasons. Learning the bonus from recent games cut the calibration error 17-fold. Full write-up.
